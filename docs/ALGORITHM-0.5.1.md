# 0.5.1 默认推进损耗8%

2026-10-18，用户明确指定默认推进损耗为**8%**。本版完成预填值、界面假设标识、测试、版本与交付更新；原理想模型、匹配优先级和适用边界不变，见[ALGORITHM-0.5.0.md](ALGORITHM-0.5.0.md)。该文件中“等待损耗数值”的旧记录已由本次明确指令解决。

- 新窗口与清空／重载后的`roughLossPercent`预填字符串`8`，表示8%，不是0.08%或0.1%。允许更改、清空或填写未知；非零读数不会悄悄回到默认值。
- 仅在粗估模式、无匹配并满足理想后备适用条件时，采用`P推进=P理想/(1−8/100)=P理想/0.92`。其后再计辅助功耗与用户倍率，不重复扣能量或时间。
- 只计推进、无其他倍率且同能量时，时间为未扣损耗理想值的92%。有辅助功耗时按总功率计算，不能简单统一减时间8%。
- 主结果显示“损耗8%（假设）”，可选字段明确“用户指定假设”；详细依据说明不是实测或独立校准。不得把该值解释为真实电机效率、电池健康或已验证误差。
- 有匹配台架时使用原台架功率，不额外叠加这项损耗。有依据的电流等效、严格模型与独立实飞评级保持原规则；8%不能为它们补证。
- 用户明确改成未知／空时，才给“未扣推进损耗的理想等效值”；明确0保留为0假设。非法、100%等输入只跳过对应理想分支，不阻止其他有效分析。

本版沿用标准海平面、正方形四轴和独立桨盘假设，重叠、低马赫数条件失效、缺桨径或已有匹配但推力超覆盖时停止理想后备；涵道／Whoop不套开放桨模型。没有增加新物理系数、数据记录或依赖，也没有修改匿名库和独立许可。

132项计算测试包含默认8%、除0.92、相应时间比例、未知／0区分、不评级及台架不重复扣减。页面和实际EXE检查见`outputs/v0.5.1/验收记录.md`，不能直接沿用旧构建的通过结论。

**8%是用户设定的粗估假设；公式与程序验证不是实机预测准确性验证。** 默认值完成不代表已校准真实损耗、真实推力能力、环境或整机续航。
