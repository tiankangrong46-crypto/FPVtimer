# 0.3.0 匿名参考库接入与计算边界

本版在0.2.0四分支基础上接入离线匿名候选库0.1.0。原算法见[ALGORITHM-0.2.0.md](ALGORITHM-0.2.0.md)；本说明覆盖其中输入和参考库方面的旧状态。没有新建账号、云服务、数据库或历史记录，没有运行时联网。

## 数据位置与准入

唯一产品数据源是项目`reference-library/v0.1.0/`，由`src/data/reference-library.ts`静态引用七份JSON和manifest；没有再复制一份产品数据。压缩包是原交付归档，不是第二个运行时数据源；整理／下载脚本不进入程序启动流程。

快照包含289个定子规格／KV组合、149个桨叶目录几何、1054组匿名台架曲线、6035个台架点、519段同电压候选。部分电机组合没有候选段，部分曲线桨叶几何未知。实飞参考与工况k均为空。数量不是独立样本数量，也不是全电机覆盖或整机准确性证明。

应用加载边界检查结构版本1.0.0、库版本0.1.0、文件／字段白名单、匿名编号、正有限数、节数、功率V×I导出舍入、父组／电压／几何隔离、递增推力与非递减功率、覆盖统计及空实飞／k。数据转为只读输出。版本或内容不合格时返回“参考库不可用”，不阻断基础评估、等效、压降或有效人工台架。

七份文件SHA256、字节数及计数由原库离线验证器和应用测试检查，构建先执行验证。静态JSON不存在运行时单独下载／文件读取；缺文件或JSON语法破损会阻止构建，避免分发损坏包；已经打包后对结构不合格内容的处理仍为明确降级。不引入运行时哈希依赖。

业务数据行、候选结果不含品牌、厂商、产品名称、来源字段或外部链接，不根据匿名ID查询品牌。独立`LICENSE-ATTRIBUTION.md`不参与匹配／计算、不放主结果界面：构建时复制到交付目录，并作为Tauri资源安装到`licenses/reference-library-0.1.0-LICENSE-ATTRIBUTION.md`。分发独立EXE时需同附许可文件。

## 输入

- 主要电机信息为定子规格字符串＋KV，不要求品牌或完整型号。规格支持0802、2306、2806.5，保留前导零，高度最多一位小数；2306.0规范化为2306，不以尺寸数值插值。库外规格允许自由输入。空、未知、非法分别处理，非法规格只跳过候选；必填KV仍使用原有正数与一位小数校验。
- 桨径／螺距手输仍最多一位小数，叶片数整数。可选库内精确几何来自桨叶目录与同电压段几何的去重并集，避免仅在台架段出现的几何无法选择。选择后停用手输几何、保留原始字符串，计算读数采用所选原精度；不会将1.22英寸变为1.2。返回手输时恢复原值。
- 型号字符串不用于猜几何。非法几何选择只给可选警告，不回退到之前的几何制造匹配。
- 人工精确台架继续保留独立入口：飞机完整电机型号移到可选人工台架区域，与记录完整型号逐项核对。定子规格不写入完整型号，不自动确认匹配、电调或来源。匿名候选不能为人工分支补证。

## 同类候选分支

`src/domain/category-bench.ts`管理类别检索和推力插值；`analysis.ts`统一整合，`endurance.ts`明确记录其不足。本分支只产生候选信息，不输出时间、评级或替代人工台架输入。

1. 精确匹配定子、KV、桨径、螺距、叶片数、节数；不采用邻近KV、尺寸缩放或无来源容差。2306／1850KV在当前库无对应组合，明确显示暂无匹配候选。
2. 查询覆盖可用于任意输入；数值候选仅用于普通开放桨四轴、用户选择无明显风的静态悬停。结构、分组、风况未知，或巡航／花飞／竞速、Whoop／涵道时不套普通悬停模型。
3. 每电机目标推力为重量g／4 gf，转换成N复用`bench.ts`。适配器显式把库的`thrustGf`映射到`BenchPoint.thrust`并使用gf单位，不强制类型转换或把gf当N。
4. 只取`constant-voltage-segments.json`，每段独立、只在覆盖推力内线性插值。端点可用，不外推。完整`bench-curves`仅用于一致性核查，不能跨列电压插值。不同父组／段／电压都保留ID，不拼点或平均原始点。
5. 展示每段测试电压、单电机候选W、覆盖、版本和匿名段／父组ID；候选折叠展示，主结果仍只有评级／时间／一句依据。测试电压不等于起飞静置电压或全程负载电压；无对应工况负载依据时不能套用于工况预测。
6. 全部候选的电调计入、装配、温度仍未知，实飞验证仍为none；功率只是表列V×I重算，不宣称已核实含电调的电池侧功率。用户确认自己的配置也不能补证原实验未知项。

所以，即使输入可用Wh、辅助功耗或自己的配置确认，这批匿名数据也不会产生台架续航时间或正常评级。未来如需范围，只能对逐段候选结果取最小／最大并标注候选值范围，不能称置信区间；本版直接逐段展示。

## 保留的续航与电池分析

独立实飞参考→完整型号人工台架／可用Wh→已核实本次平均电流与目标Q等效→参考不足的原有流程保留。独立实飞与k准入不放宽，台架库不填入它们。本次数据仍不能反证本次正常；没有Q／Wh／辅助功耗不填默认值，不假设80%，不额外用压降扣续航。

候选缺失、损坏或工况不适用时，其他有依据的分析继续计算。压降和回弹的来源、时点及条件规则不变，主结果不推断电池损坏或健康百分比。

## 验证的意义

应用测试直接用真实库中的0702／23000KV、1.2×1.9英寸三叶、1S段核对10gf插值；也验证真实同父组3.93／3.92／3.91V分段的推力间隙不能跨电压补齐。库内原始值不是本项目重新实测。

公式、隔离、边界与降级检查不能证明原始实验准确性、用户电机与匿名类别的可迁移性、预测误差或电池健康。合格实飞、独立工况校准、已核实电调／装配／环境台架及适用电池Q／Wh仍缺。当前运行结果及打包限制见`outputs/v0.3.0/验收记录.md`，不复用旧版已通过项。
