# 0.5.0 理想悬停后备模型

2026-10-18。用户要求“有匹配数据直接计算，没有时用通用模型，超出适用范围停止”，并提出损耗小系数。本版保留0.4.0的匹配／电流／假设路径，新增有明确适用范围的理想物理模型后备。旧算法见[ALGORITHM-0.4.0.md](ALGORITHM-0.4.0.md)。

用户已选择需要预填损耗，但尚未指定百分比，因此当前临时构建不预填任意小系数。字段空／未知时显示“未扣推进损耗的理想等效值”；允许用户填写百分比并明确标为假设。最终默认值须等待用户数字后更新。空／未知不表示实际损耗为零，0是明确输入的理想假设。小损耗不保证能接近实飞。

## 分支顺序

1. 原有独立实飞、严格完整型号台架、有依据电流＋目标Q等分支保持原准入和优先级。
2. 在粗估模式中，已核实本次电流＋用户容量比例仍先给等效续航。
3. 有匹配匿名同电压段且覆盖目标推力，仍逐段插值计算原有假设时间。新损耗只作用于理想后备，不在已有台架电输入功率上再扣一次。
4. 无匹配、没有足够匹配字段或库不可用时，在普通开放桨四轴的理想模型适用条件内可输出后备时间。它不要求准确电机型号、定子或KV匹配，也不由这些字段推准确功率。
5. 已有匹配台架但目标推力超其覆盖，不借后备模型绕过；涵道／Whoop、未知机型组、非四轴、无有效桨径、桨盘相接／重叠、低马赫数假设不成立或非法损耗时停止相应后备估算。有效电流等效等其他分支仍可用。

标准评估模式不自动启用后备。主结果标为“理想模型粗估”，突出时间、主要能量／损耗假设；不能生成正常／偏短／较长或电池健康结论。

## 公式与单位核实

对四个等径、相互独立的开放桨盘，在无风自由空气中准静态悬停、均匀承重：

```
D_m = 桨径英寸 × 0.0254
A_total = 4 × π × (D_m/2)²           m²
T_total = 重量g / 1000 × 9.80665     N
v_i = sqrt(T_total / (2ρA_total))    m/s
P_ideal = T_total × v_i              W
```

也等于四个单桨分别按`T/4`和`A/4`计算后相加，不能把整机推力放进单桨面积再重复乘4。模型只给理想诱导功率，尚未加入桨叶型面阻力、非均匀流、电机电调等全部实际损耗；其理论背景不等于这些损耗已经验证。

密度固定采用1976标准海平面情景`ρ=1.225kg/m³`，声速取同情景近似`340.3m/s`；不是现场温度／气压实测。单独温度不能确定密度，因此不会拿温度输入自动猜密度。

## 适用范围

- 普通四轴、开放桨。默认理论情景是假定正方形布局、等径独立桨盘、均匀承重，忽略机架与地面效应；这些是情景假设，不是自动识别出的真实装配。
- 使用已有机架对角轴距L，正方形相邻轴距为`L/√2`；要求桨径mm严格小于该间距。相接／重叠停止该模型。其他布局未建模，不能靠该检查宣称实际装配已确认。
- 不可压近似只限低马赫数。理想远尾流速度为`2v_i`，本版在该远尾流马赫数达到0.3时停止后备，避免把明显不适合不可压近似的极端输入代入。此阈值是模型适用性筛查，不是续航评级或准确率保证。
- 桨尖速度、真实最大推力、转速、热限制和真实电机能否悬停尚不能由现有字段核实。即便有一个理想时间，也不证明动力足够。
- 巡航／花飞／竞速及实际有风时，依然只能视为假设下的无风悬停等效，或在用户明确功耗倍率下的场景；不自动提供通用工况k。

## 损耗的定义与时间

若用户明确输入推进损耗假设L（0至小于100%，最多一位小数），定义：

```
η_assumed = 1 − L/100
P_propulsion = P_ideal / η_assumed
P_scenario = (P_propulsion + P_aux) × 用户功耗倍率
t_min = 60 × E_available_Wh / P_scenario_W
```

该η是“理想诱导功率／假设推进输入功率”的综合比例，不能称为实测电机电效率。只有不计辅助且无其他倍率时，时间才等价于理想时间乘`1−L/100`；本版通过功率统一处理，避免先加功耗又随意扣时间。已经匹配到台架电功率时不再应用这项损耗。

L空／未知只输出未扣推进损耗的理想情景，不替用户填5%、10%等默认值；非法或100%等读数只跳过该后备，不能悄悄变未知。明确0与未知结果可能同数值，但依据和数据状态分别保留。

能量、容量比例、辅助功耗、用户倍率沿用0.4.0规则：有依据Wh优先；否则化学类型标称能量及明确比例／全部可用假设。未知辅助仅计推进情景，不认定图传功耗为零；未知倍率只给悬停等效。LiHV标称值依然需标签选择或有依据Wh。

单一理想情景只显示单一等效值，不人为拉成一个误差区间。它不是实际可飞时间、保证时间或安全上限。

## 核实来源与检验边界

- [NASA推进动量理论](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/propeller-thrust/)：推力、桨盘面积与气流动量的关系及简化假设。
- [NASA旋翼理论](https://rotorcraft.arc.nasa.gov/Publications/files/NASA%20TP-2009-215402-app3.pdf)：理想诱导功率`Tv`及实际非理想诱导／型面功率的分别处理。不能拿仅修正诱导损失的小因子代表所有推进损耗。
- [1976标准大气资料](https://ntrs.nasa.gov/api/citations/20060053240/downloads/20060053240.pdf)：海平面密度1.2250kg/m³。
- [NASA声速教学资料](https://www.nasa.gov/wp-content/uploads/2023/02/speed_of_sound_9-12.pdf)：海平面声速近似340m/s。
- [航空教材的不可压流条件](https://eaglepubs.erau.edu/introductiontoaerospaceflightvehicles/chapter/types-of-fluid-flows/)：低于约Mach0.3的近似适用性。本版用远尾流速度筛查，不声称已核实桨尖流动。

独立解析算例：总推力8N、总盘面积1m²、密度1kg/m³，`v_i=2m/s`、`P=16W`；分成四个独立桨盘也应为16W。单位、四桨求和、质量／桨径／密度缩放、损耗与辅助功耗组合、范围边界通过必要测试。

额外对库中已知几何的2943点进行只读诊断，按相同理论计算单桨理想功率／表列电功率比：中位数约0.391，103点大于1。实验条件与几何解析等仍有未解决不一致，不能把该统计当通用效率、拟合系数或实机精度验证。没有据此生成默认损耗。可用`node --import tsx scripts/ideal-model-audit.mjs`复核，结果只在开发验收目录，不导入应用计算库。

**本次检验的是理论来源、量纲、解析算例、软件分支和诊断，不是独立整机实飞验证。** 没有“经过实机校准的通用功耗模型”，也没有借很宽的误差范围声称准确。原始匿名数据、许可、正式实飞／k空库均保留。

实现：`ideal-hover.ts`为唯一理想公式／损耗转换，`rough-estimate.ts`共享能量／功率／时间组合，Vue只显示参数和结果，Rust不复制算法。当前交付／已验证项见`outputs/v0.5.0/验收记录.md`。
