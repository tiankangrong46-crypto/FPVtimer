# 0.6.0 所选工况理论参考与实际时长对比

2026-10-18。本版按最新用户要求替换历史8%／13%和任意功耗倍率。目标是告诉用户这架四轴在所选工况下的理论参考时间，与其输入的实际时长差多少。默认启用粗估模式（理论参考与比较），标准评估仍独立保留。旧版说明见[ALGORITHM-0.5.2.md](ALGORITHM-0.5.2.md)。

## 用户假设与唯一配置

`structure.ts`只向主界面提供裸桨、圈圈两个选项。裸桨损耗35%，圈圈45%；涵道／Whoop归入圈圈只是用户指定分类，不表示气动特性相同。初始／清空为裸桨35%；切圈圈填45%，切回裸桨填35%，提示会重填。用户仍可改、清空、未知或明确0；非法损耗只阻断相应理想分支。

`flight-scenario.ts`唯一维护方式时间系数：悬停1、巡航0.8、花飞0.65、竞速0.4。全部是用户指定假设，不进入独立实测校准库。旧`roughPowerMultiplier`输入、类型、解析和计算入口已移除。不是功率乘数，也不除以方式系数。

## 理论参考计算

```
A总 = 4π(D/2)²
T = 起飞质量kg × 9.80665
P理想 = T√(T/(2ρA总))
P推进 = P理想 / (1−L)
P总 = P推进 + P辅助
T基础(min) = 60 × E可用(Wh) / P总(W)
T工况 = T基础 × F方式
```

理想功率仍唯一由`ideal-hover.ts`实现，标准海平面ρ=1.225kg/m³、正方形四轴及独立桨盘等适用限制沿用0.5.0。裸桨除0.65，圈圈除0.55；损耗只在功率侧扣一次，不叠加旧参数。最终时间系数只由`applyStyle`应用一次，不改变基础功率或能量。内部悬停基线只在折叠依据展示，巡航／花飞／竞速主结果明确标为对应工况理论参考时间。

理论分支顺序：

1. 完整型号且满足原来源、单位、电输入、装配、匹配和推力覆盖要求的台架：复用`modelEstimate(...,'hover-baseline')`取得静态基础时间，最后乘F。不需要实测k来生成用户假设场景；不叠加35%／45%。原`strict`模式仍按独立k规则工作。
2. 裸桨有匹配匿名同电压段：同组同电压覆盖内插值，`P总=4×P单电机+P辅助`，不叠加结构损耗；每段基础时间最后乘F。未知字段不改成确认，组／电压不拼接，超覆盖不外推。
3. 无适用匹配时走有效范围内的理想后备。圈圈不使用裸桨匿名功率，只使用理想基线与用户损耗假设，未模拟涵道增升／气流干扰。
4. 缺少有效桨径、几何不适用、未知必要量或无有效功率等条件仍可能无法生成理论参考。裸桨已有匹配但超推力覆盖时不借理想模型绕过。

能量规则不变：有充分依据且适用的目标可用Wh优先；否则按LiPo标签标称3.7V／节，或用户明确选择LiHV标签3.80／3.85V估算标称Wh，容量比例未知时明确“假设标称能量全部可用”。辅助未知只给“仅计推进功耗”场景，不当实测0W。不用起降电压均值或电压差线性换算容量，不默认80%。

## 本次数据与比较隔离

理论分支不使用实际飞行时长、消耗mAh或本次平均电流。原有已核实电流＋目标容量（含粗估时用户明确容量比例）的等效分析独立保留在原分析依据；它不是理论参考，不能用于自己评价自己。没有有效理论时间时，可以继续显示有效等效信息，但没有理论比较卡片。

`compareFlightTime`只在理论计算完成后计算：

```
实际分钟 = 实际秒 / 60
差值 = 实际 − 理论参考
达成率 = 实际 / 理论参考 × 100%
```

差值保留正负，达成率不截断100%，零／非法参考拒绝除法。若参考为场景范围[R低,R高]，差值范围为[实际−R高,实际−R低]，达成率范围为[实际/R高,实际/R低]×100%。这是候选／假设场景范围，不是统计置信区间或经验证误差。

可选“本次与理论目标的电量区间／结束条件”支持未知、一致、不同、提前落地。只有用户确认一致、目标能量区间依据完整、两端停桨电压与目标端点相同才注明“用户确认一致，尚未独立核验”；不从电压推电量。其他情况明确“使用区间可能不同，不能据此判断性能异常”。该条件仅影响比较说明，不改变理论时间。

主结果显示所选结构／方式、工况理论时间、实际时间、差值与达成率，附“基于用户指定损耗及飞行方式系数的理论情景，未经实机校准”。能量／仅推进等假设继续展示；基础功率、基线、时间系数、数据编号及缺失项折叠。

正式实飞参考匹配和独立验证评级保持原规则，不能被本次用户系数改成“正常／偏短／优秀”。有实飞参考时，理论比较与正式评级分别显示，不改实飞记录中位数或区间。所有输入变化使旧结果失效，无持久化。

## 验证和局限

计算测试验证两结构、四系数只乘一次、计算顺序、实际时长隔离、台架不重复扣减、比较正负和超过100%、分母保护、区间说明、正式评级隔离及旧边界。页面与实际EXE检查验证结构、工况、重置、失效和离线完整操作。当前证据见`outputs/v0.6.0/验收记录.md`，旧测试不直接沿用。

没有独立实机校准35%／45%或四种方式系数，没有真实整机预测精度验证。它们是用户定义的理论情景，不是保证／安全上限或电池健康结论。匿名库7份JSON、manifest和许可未修改；没有新增参考记录、依赖或联网功能。旧EXE保留，不自动安装新版。
