# 0.4.0 粗估模式

2026-10-18。用户本次明确允许在独立评级依据不足时输出有标识的假设时间。本版增加独立粗估分支，覆盖0.3.0说明中“匿名库只能展示功率，不能组成任何时间”的限制；原严格台架准入、正式评级规则和数据未知标记不放宽。旧算法见[ALGORITHM-0.2.0.md](ALGORITHM-0.2.0.md)，匿名匹配与数据边界见[ALGORITHM-0.3.0.md](ALGORITHM-0.3.0.md)。

## 操作与结果

默认仍为“标准评估”。切换“粗估模式”后，可在“可选电池分析→粗估假设”填写可用容量比例、辅助功耗和平均功耗／悬停功耗倍率；全部可空或未知。普通开放桨场景需选择相应配置分组，不能将涵道／Whoop或未知分组默认为开放桨。

有任一估计／等效时间时，主结果突出时间和一句主要依据；“尚不能评价本次是否正常”只作次要说明。仅独立实飞验证区间可给正式评级。内部`rating=参考不足`是“未评级”状态，新增粗估不会改成正常／偏短／较长，也不输出电池健康结论。无有效依据时仍可显示“暂无法估算”。

结果类型区分实测参考、原严格模型“模型粗估”、本次“等效续航”、新增“粗估”和“标称能量等效”；详列假设、匿名组／段ID、库版本、测试电压和缺失条件均折叠显示。

## 决策顺序与数据路径

现有独立实飞参考、严格完整型号台架、有依据本次平均电流＋目标Q等效保持原有顺序与准入。已有有效时间不被新增分支覆盖。它们均无法给时间且用户启用粗估后，新增路径依次尝试：

1. **有依据的平均电流＋目标容量**。继续只采用用户确认已校准、同一飞行时段的正平均电流或放电积分。目标Q优先使用原有完整区间／依据的数据；否则可用用户明确填写的容量比例形成`Q=标称mAh×比例/100`假设。`t=0.06×Q/I平均`，显示等效续航。没有Q或比例，不在纯电流路径自动补100%容量。
2. **匿名候选＋Wh**。复用类别匹配与单段推力插值。优先采用有依据／明确假设且区间完整的目标可用Wh；否则使用核实化学类型的标称单节电压计算标称Wh，再按用户容量比例折算。没有比例时可按本次授权给“假设标称能量全部可用”的标称能量等效场景。
3. **无法估算**。候选、几何、推力覆盖、化学标称值等依据不足时明确说明，不补邻近KV、经验系数或任意功率。可用压降、回弹、实际时长与电流读数仍保留。

有依据的目标Wh或Q优先时，不再重复乘容量比例。新辅助功耗／倍率非法不阻断原有有效等效。未经校准的电流、充电器回充量继续只作填报信息，不当作本次放电积分。

## 功率、工况与电压

`src/domain/category-bench.ts`复用同一匹配／插值实现，新增`hover-scenario`作用域供粗估使用。精确匹配定子字符串、KV、桨径、螺距、叶片数、节数；不用品牌，不猜几何，不借邻近规格。普通四轴单电机目标`重量g/4 gf`，显式转换为N调用现有插值。

每个同父组、同表列测试电压段独立计算，只在推力覆盖内插值，端点可用。不同组不拼点、不平均原始点；不跨电压或区间外外推。完整多电压曲线不能代替同电压段。数据仍为未知电调计入、未知装配、未知温度和无实飞验证；没有把unknown写成已确认。

每段`P≈4×P单电机+P辅助`。用户明确填了辅助功耗时用该假设；未知时另给“仅计推进功耗”场景，不能声称辅助设备功耗为0。明确输入0W可计算，但依据标明这是用户假设，与未知分开。

没有用户功耗倍率时，只给**无风静态悬停等效**，即便当前飞行选择巡航、花飞、竞速或风况未知／有风，也不冒充该实际工况的时间。用户明确输入正倍率后，`P场景=(4×P单电机+P辅助)×倍率`，倍率作用于含辅助功耗的总功率，可小于1，必须标为假设而非独立k。原严格模型依然需要独立工况k，不能借用该假设。

测试电压不是起飞停桨电压，也不等于飞行平均负载电压。本版不按起飞电压筛选或跨电压插值，而是逐段展示各测试电压下的场景，明确尚未匹配本次飞行电压。同规格／KV／几何不等于同产品或相同效率。涵道／Whoop缺对应装配数据时不套开放桨粗估。

## 能量、标称电压与范围

- `标称Wh=容量mAh/1000×节数×标称单节V`。不用起降电压均值，不线性换算电量。
- LiPo使用核实的常规标称3.7V／节；这不是满充、落地或储存电压。
- LiHV仅凭类型不能在不同标称值间猜测。本版在可选区提供标签3.80／3.85V选项，默认未知；用户须按标签选择。不支持或未知时需独立可用Wh，否则跳过这条能量路径。电流＋有依据Q不需要该电压值。
- 比例大于0且不超过100%，最多一位小数。将容量比例同样用于标称能量本身也是明确近似，不模拟放电曲线。未知比例不默认为80%；只在授权的标称场景中明确假设全部可用。
- 倍率最多三位小数且必须为正，辅助W最多一位小数且可明确输入0。空／未知和非法／零倍率分开；非法比例、非法辅助或倍率不偷偷切到完整能量、仅推进或悬停路径。原有其他有效分支可继续。
- `t分钟=60×可用Wh/P平均W`。逐段结果形成的范围，按`最短=60×能量下值/功率上值`、`最长=60×能量上值/功率下值`计算。本版每次使用单一能量假设，故能量上下值相同，功率来自独立候选场景；不取中位数伪装最佳预测。

这是输入假设与候选值组成的场景范围，不是统计置信区间、经验证误差、实际可飞时间、保证时间或安全上限。没有按内阻压降再随意扣减时间。

核实来源（仅说明文档，未添加进匿名业务数据）：[额定电压技术手册](https://www.genstattu.com/content/IMARSD300Manual.pdf)列出LiPo3.7V与LiHV3.8V；[高压电芯技术说明](https://www.grepow.com/lihv-battery/.html?page=1)说明LiHV标称范围存在不同规格。因此LiHV不使用一个静默固定值，需用户标签值或直接Wh。

## 实现与证据边界

- `rough-estimate.ts`是新增粗估和场景范围的唯一实现；复用`bench.ts`、`endurance.ts`已有单位、功率插值、Q/I和Wh/W换算，不在Vue或Rust复制公式。
- `analysis.ts`只负责统一选择和结果；Vue只收集原始字符串、显示时间／标签、格式化数值。改变模式、假设或配置使旧结果失效。
- 匿名原库7份JSON、manifest及原许可保持不变；没有修改用途／实飞验证标记或加入品牌、来源、产品字段。独立许可继续随交付与安装资源分发。0.3.0原库说明是历史用途边界，本版新用户授权允许把数值候选组成明确的未验证假设场景。
- 真实库算例验证逐段插值／换算、同电压隔离；人工测试验证范围方向、缺值、假设标签与不触发评级。这些不是本项目实机飞行或电机台架复测。

仍缺匿名类别向真实电机的可迁移性、明确功率测量边界／装配、各工况独立校准、电池适用曲线及整机实飞误差验证。当前实测正常参考与独立k均为空。本版验收以`outputs/v0.4.0/验收记录.md`为准。
