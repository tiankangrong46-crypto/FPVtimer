# 0.7.2 淡蓝主题发行

日期：2026-10-19。页面由浅灰绿调整为淡蓝色；本版不改变计算算法、参考库、参数或表单行为。

- `src/style.css`用CSS变量统一页面、面板、按钮、选中态、输入焦点及结果强调色。淡蓝底`#eef7fd`，白色面板，淡蓝按钮`#c4e4fa`配深蓝文字；错误和警告仍保留红色、琥珀色。
- Tauri启动背景同步为`#eef7fd`。package、npm lock、Cargo及lock、Tauri配置统一为0.7.2，窗口和页面显示本版版本号。
- 算法完整沿用[0.7.1](ALGORITHM-0.7.1.md)与[0.7.0](ALGORITHM-0.7.0.md)：结构时间裸桨0.25／圈圈0.18，方式悬停1／巡航0.8／花飞0.58／竞速0.33；均为用户假设，未实机校准。
- 新交付写入`outputs/v0.7.2/`，旧EXE、安装包与历史验收保留。独立EXE需要已有WebView2，安装包含完整WebView2离线组件及独立许可；不自动安装。
- 桌面验收脚本新增实际EXE页面版本与淡蓝颜色检查；其余交互、离线模拟和计算分支继续使用现有验收流程。

本版实际构建、测试、对象SHA256和未验证项见[验收记录](../outputs/v0.7.2/验收记录.md)。
