# 0.7.0 结构时间保留系数及机架桨径限制

2026-10-18。用户明确：桨叶用英寸、机架轴距用mm；裸桨最终时间×0.25，圈圈×0.18，替换原35%／45%功率侧损耗，不重复折减。旧说明见[ALGORITHM-0.6.0.md](ALGORITHM-0.6.0.md)。

## 结构系数的新含义

新字段`roughStructurePercent`称为“结构时间保留系数（用户假设）”，不再称功率损耗。裸桨默认25%，圈圈18%；切换重填，重置恢复裸桨25%，仍可手改、空／未知或明确0。结构映射唯一在`structure.ts`，直接时间乘法唯一在`applyStructureTime`。

理想模型分支：

```
P基础 = P理想 + P辅助
T基础 = 60 × E可用Wh / P基础W
T最终 = T基础 × 结构时间保留比例 × 所选方式时间系数
```

裸桨乘0.25，圈圈乘0.18；不是保留75%／82%，不是从功率减25%／18%，不是功率除0.75／0.82，也不再叠加旧的0.65／0.55功率修正。包括辅助功耗后的基础时间一起乘结构系数。旧`powerWithAssumedLoss`计算和`roughLossPercent`字段已从当前源码移除。

四方式系数不变：悬停1、巡航0.8、花飞0.65、竞速0.4。两个时间系数各应用一次；功率与能量不随结构时间系数而改写。主结果和折叠依据均显示实际采用的系数。

**适用分支沿用原损耗规则**：理想后备采用结构时间系数；完整型号及匿名台架已经给出电输入功率的分支继续不额外折减，以免重复计算。台架仍应用最终方式时间系数，不改独立实飞参考的正式评级、中位数或区间。结果明确是否已应用结构时间系数，不能把台架未采用的25%／18%冒充参与计算。

空／未知时明确“结构时间系数未知，未折减”，不给其填默认值，不声称实际无损耗。100%是明确保留全部基础时间；0%保留零时间，单独提示不能作为比较分母，不生成理论比较。允许0～100%、最多一位小数；负值、超过100%或格式非法只跳过对应理想模型，不阻断其他有效分支。

## 机架与桨叶限制

公开原始资料和采用范围见[FRAME-SIZES-0.7.0.md](FRAME-SIZES-0.7.0.md)。5英寸级机架可以有5～5.1英寸适配范围，不能把所有机架都限制为“级别必须严格等于实际桨径”，也不能从mm轴距唯一反推适配桨径。

新增可选“机架允许最大桨径”英寸，按实际机架说明书填写；`frame-fit.ts`统一校验。实际桨径超过上限时停止理论模型，等于／小于上限只通过该项检查；空／未知提示未核实安装适配；非法／0不当未知。用精确所选几何，不舍入、不从型号猜直径。原几何／低马赫数／推力覆盖条件继续。压降、回弹、独立电流等有效分析不因该可选项失败而崩溃或消失。

界面离线显示三个厂商机架尺寸例子，不把它们作为用户机架的自动匹配数据库，不修改匿名参考库unknown或独立许可。新字段与任何其他输入一样使旧结果立即失效。

## 比较与验证边界

理论时间仍不使用本次时长、电流或消耗量；实际时间最后才用于差值、达成率，达成率可超过100%，不产生健康／正常评级。目标电量区间或结束条件不一致／未知时继续提示不能据此判断性能异常。

测试覆盖直接乘0.25／0.18、功率侧不再修正、含辅助时间一起修正、四方式、台架不重复、未知／0／100／非法系数、桨径上限边界、精确几何、其他分析和输入失效。实际构建和桌面证据见`outputs/v0.7.0/验收记录.md`，旧结果不作为本次通过证据。

25%／18%和方式系数全部是用户假设，未实机校准；机架尺寸资料不是整机续航预测验证。保留所有旧包，不自动安装新版。
