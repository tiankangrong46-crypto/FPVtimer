# 0.5.2 涵道／圈圈机假设粗估

2026-10-18。用户指定涵道机、圈圈机损耗为13%，要求加入飞机结构选项。此授权覆盖0.5.1及历史版本中禁止该类理想假设场景的限制；仅放宽粗估理想后备，不放宽实飞评级、严格台架或匿名候选准入。前版说明见[ALGORITHM-0.5.1.md](ALGORITHM-0.5.1.md)。

## 输入与界面

- 飞机配置中的“飞机结构”统一为开放桨四轴、涵道四轴、圈圈机／Whoop、四轴装配未知、其他结构；原可选分析中的重复分组控件移除。内部保留`aircraft`和`configurationGroup`分别参与原有严格算法。
- 初始／清空后明确选择普通开放桨四轴，损耗8%。切换到涵道或Whoop时填13%，切回开放桨填8%，选未知或其他填未知。标签和提示明确切换会重填损耗。该映射唯一维护在`src/domain/structure.ts`；Vue只调用映射，不计算功率。
- 所有损耗都是用户指定的总综合损耗假设；13%替换8%，不是13%＋8%。用户可在可选分析中修改、清空、填未知或明确0；不自动确认任何测试条件。
- 粗估仍需显式选择“粗估模式”。任意结构／损耗变化使旧结果立即失效；重载不保存记录。

## 计算与降级

1. 独立实飞、严格台架、有依据电流等效按既有条件优先；电流等效不因结构损耗再扣一次。
2. 开放桨的匿名匹配和覆盖内插值保持原规则，有匹配段但推力超覆盖仍停止；不跨组、电压、KV或范围。
3. 涵道／Whoop不使用开放桨匿名功率。即使定子／KV／桨叶相同、匿名返回unsupported或超开放桨推力覆盖，该段仍不适用涵道，另行使用下面的明确假设场景，不修改原库unknown或组别。
4. 使用已有理想桨盘功率基线`P理想=T√(T/(2ρA总))`，默认涵道／Whoop为`P推进=P理想/(1−13/100)=P理想/0.87`；随后加用户辅助功耗并乘用户工况倍率。时间仍为`60×可用Wh/P平均`，能量不再重复扣13%。其他量和未知策略见0.5.0／0.4.0。
5. 这是**理想桨盘基线＋用户假设**，不是涵道空气动力模型。没有计算涵道增升、桨尖间隙、进出口面积／扩散比、安装干扰；13%不是实测校准，不保证实际可悬停或接近实飞。四桨面积按真实桨径，不能用护圈外径。
6. 仍检查四轴、有效重量／桨径／轴距、正方形布局桨盘不相交、低马赫数和有效损耗。未知结构、非四轴、缺有效桨径、几何或数值条件不满足时停止理想分支；不阻断其他有效分析。
7. 输出“理想模型粗估”、涵道或圈圈机假设场景、损耗13%（假设），折叠显示未建模条件。不能输出正常／偏短／较长或健康结论；标称能量全部可用、辅助未知仅计推进等假设仍明确列出。

## 物理核查与证据边界

NASA的[涵道推进器实测与建模报告](https://ntrs.nasa.gov/citations/20250009190)和[NDARC理论](https://ntrs.nasa.gov/api/citations/20170011635/downloads/20170011635.pdf)说明涵道系统不能仅凭开放桨数据视为同一工况，模型涉及涵道／转子推力分配及流场。这里没有声称13%来自这些资料；仅按用户要求提供可编辑的假设场景。程序单元测试验证公式、隔离和分支，不能证明涵道续航预测准确。

没有新增产品参考数据、依赖、数据库或联网功能。匿名库7份JSON、manifest及独立许可保持原样。当前测试和新版EXE验收见`outputs/v0.5.2/验收记录.md`；旧版记录不作为本次通过证明，不自动安装新版。
