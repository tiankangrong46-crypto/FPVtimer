## 匹配和计算规则

1. 精确匹配定子规格、KV、桨径、螺距、叶片数、节数；任一未知就跳过对应计算并说明。不要使用邻近 KV、比例缩放、定子体积经验公式或任意相似度。当前库没有 `2306+1850KV`，应明确显示“暂无匹配候选”。
2. 桨叶类别仅是几何相同，不证明翼型／材料／品牌相同；同定子＋KV 也不证明绕组、效率或电调相同。不同 `curveId` 必须保留，不把不同测试组的点拼成一条曲线。数量不等于独立样本量。
3. `bench-curves.json` 的同一组可能含多个表列电压，不能直接跨电压插值。数值插值只能使用 `constant-voltage-segments.json` 的单段，在同一个 `curveId`、同一个测试电压的覆盖推力区间内进行，端点可用，区间外不外推。
4. 测试电压不等于起飞前静置电压，也不等于整个飞行的负载电压。不要仅凭节数匹配后忽略实际电压，不设无依据的 ±电压／KV 容差。可以展示各测试电压下分别得到的候选值；要把某段用于特定工况，必须说明所需负载电压依据。没有依据就停留在候选展示。
5. 普通四轴静态悬停，`T每电机(gf)=起飞重量g/4`；等价牛顿形式为 `(重量g/1000)×9.80665/4`。仅对覆盖此推力的候选段插值。先分别算每段的候选功率，不能先平均原始点。多组结果的最小／最大值仅为“候选值范围”，不得称为置信区间、正常范围或准确率。
6. 所有记录的 `escInclusion`、`assembly`、`temperatureC` 目前未知，`flightValidation` 为 none。`electricalPowerW` 只是表列 `voltageV×currentA` 重算，不能自动宣称是已核实含电调损耗的电池侧功率。用户确认自己的配置不能补证原始实验未知条件。
7. 因此本次库接入可以完成检索和有明确测试电压的**同类台架候选功率展示**，不能仅靠这批数据启用正式台架续航时间或评级。不要为了“导入后必须出数”删除原有准入要求。缺少条件时保留“参考不足”，同时允许其他有依据的等效续航／电池分析正常显示。
8. 未来若有符合条件的独立台架数据，普通无明显风悬停可用 `P整机≈4×P每电机＋P辅助`、`t分钟≈60×可用Wh/P整机`。可用 Wh 与辅助功耗须有明确依据／已标注假设；不默认 80% 标称容量，不默认辅助功耗为 0。不要按起降电压差线性算电量。
9. 巡航、花飞、竞速不得使用统一 k；涵道／Whoop 必须具备对应装配与独立校准，不能因库里包含小尺寸电机就自动支持。没有数据就跳过该工况模型。
10. 本次飞行时间、电流或消耗 mAh 可用于原有耗电率／等效续航，不能反过来构造本次正常参考。不得把台架库或等效结果称为独立实飞验证。

主结果保持简短：续航结论／缺失状态＋一句原因。新候选信息放可选或折叠区，包含测试电压、同类候选功率或跳过原因；不展示品牌和来源。依据中可以保留匿名段 ID、库版本、匹配字段及未知条件。
