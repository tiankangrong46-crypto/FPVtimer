# Android 0.7.4 build 7005 验收

2026-10-21。本次为Android局部界面调整，保留既有未提交修改，未提交／推送、未安装到真实手机。Windows版本仍为0.7.4，原交付及历史build7004文件保留。

## 实际改动

- Android移除电机定子规格旁“未知可跳过候选”，避免标签换行推低输入框；定子仍选填，校验与匹配规则不变。
- 操作区主按钮居中，清空改为白底描边次按钮，统一最小高度52 CSS px、间隔12px；手机不显示桌面箭头及Ctrl+Enter文字。隐私说明调整为12px，操作区与上下内容分隔。
- 使用Android UA作用于独立`android-app`样式，Windows保留原标签、箭头和按钮尺寸。无domain、Rust、算法系数或匿名数据修改。
- Android版本码由7004提高为7005，版本名仍0.7.4；构建目录和文件名带版本码，同版本名修订不会覆盖旧交付。
